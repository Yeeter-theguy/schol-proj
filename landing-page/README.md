# Landing Page - แผนกเทคโนโลยีสารสนเทศ

ไฟล์ตัวอย่าง landing page โดยใช้ `html`, `css`, `javascript` พร้อมธีมสีขาว-เขียว โทนสว่าง

การใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือรันด้วย simple server เช่น:

```bash
# Python 3
python3 -m http.server 8000

# แล้วเปิด http://localhost:8000
```

ไฟล์สำคัญ

- `index.html` — หน้าเว็บหลัก
- `styles.css` — สไตล์สำหรับหน้า
- `script.js` — พฤติกรรมเล็ก ๆ เช่นเมนูมือถือ และ smooth scroll

หมายเหตุ

- รูปภาพและไอคอนถูกดึงจาก CDN (Unsplash, Font Awesome)
- ปรับแต่งเนื้อหา และรูปภาพตามต้องการ
